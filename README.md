# Udseen

【声明】本项目编写过程中部分使用人工智能技术辅助

逻辑式视觉小说引擎与编辑器

逻辑式视觉小说编辑器，基于 Electron + React + PixiJS 构建。

## 概述

Udseen 是一个集成的视觉小说开发环境，包含：
- **脚本编辑器** — 基于 Monaco Editor 的 .ykn 剧本编写环境
- **实时预览** — PixiJS 驱动的 2D 演出渲染
- **脚本引擎** — 自定义语法解析器与运行时
